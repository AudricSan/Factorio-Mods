# Sources graphiques d'Electrified Railways

Images de référence et scripts Python (Pillow) qui produisent les graphismes du mod. Les résultats sont écrits dans `ElectrifiedRailways/graphics/` et `ElectrifiedRailways/thumbnail.png`.

| Fichier | Rôle |
| --- | --- |
| `Atlas de caténaire ferroviaire.png` | Atlas source des sprites de caténaire et des icônes |
| `Locomotive rouge sous caténaire électrique.png` | Illustration source de la vignette |
| `make_catenary_sprites.py` | Découpe l'atlas en sprites de caténaire |
| `make_icons.py` | Génère les icônes des objets et des technologies |
| `make_thumbnail.py` | Génère `thumbnail.png` et `portal-banner.png` |
| `portal-banner.png` | Bannière pour la page du mod sur le portail |
