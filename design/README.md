# ElectrifiedRailways — isometric catenary sprite prototypes

Transparent RGBA PNGs with pixel-art shading and isometric depth cues.

These are **prototype assets**, not yet wired into the Factorio prototypes. The wire sprites are illustrative and should only replace dynamic rendering after testing straight, diagonal and curved rail connections. The current Lua line-rendering approach remains better for variable rail geometry.

Files:
- `pole-steel-iso*.png`: shaded lattice pole with isometric footing and side bracket.
- `gantry-beam-iso.png`: isometric lattice beam concept.
- `brace-iso-*.png`: diagonal braces.
- `insulator-iso.png`: ceramic/copper insulator.
- `messenger-wire-droppers-iso.png`: messenger wire and droppers.
- `contact-wire-iso.png`: copper contact wire.
- `preview-atlas-iso.png`: labelled preview only.

Before integration, test in Factorio 2.1 for pixel scale, sprite offsets, shadows, render layers, and orientation.
