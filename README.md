# Factorio Mods by AudricSan

Bienvenue dans mon dépôt de mods Factorio.
Ce projet contient l'ensemble des mods que j'ai conçus ou que j'ai forkés pour leur maintenance.

## Contenu du Projet

### [Electrified Railways](ElectrifiedRailways/README.md)
Fusion des idées d’ElectricTrainFix et de James-Train-Mod en un seul mod de trains électriques, avec poteaux de caténaire, batteries en grille d’équipement et transformateurs qui alimentent les rails.

- **Version actuelle** : 0.3.15
- **Compatibilité** : Factorio 2.1, Space Age et Elevated Rails facultatifs
- **Installation** : placez uniquement le dossier `ElectrifiedRailways` dans le dossier `mods` de Factorio; les deux dossiers sources d’origine ne doivent pas être installés avec lui.

### [No Crafting Time](NoCraftingTime/README.md)
Un mod qui supprime les temps de fabrication dans Factorio. Toutes les actions sont effectuées instantanément en utilisant une petite quantité d'énergie électrique.

- **Version actuelle** : 2.0.0
- **Compatibilité** : Factorio 2.0 ou supérieur
- **Dépendances** : Base >= 2.0.0
- [Documentation complète](NoCraftingTime/README.md)

## Installation
1. Clonez ce dépôt ou téléchargez-le en tant qu'archive ZIP.
2. Copiez dans le répertoire `mods` de Factorio uniquement les dossiers des mods que vous souhaitez utiliser.
3. Pour les trains électriques fusionnés, installez `ElectrifiedRailways` sans les dossiers sources `ElectricTrainFix` et `James-Train-Mod`.
4. Assurez-vous que votre version de Factorio est compatible avec les mods.
