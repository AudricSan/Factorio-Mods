# Factorio Mods by AudricSan

Dépôt des mods Factorio que j'ai conçus ou que je maintiens.

## Contenu du Projet

### [Electrified Railways](ElectrifiedRailways/README.md)
Trains électriques : locomotive à batteries, poteaux de caténaire et transformateurs qui alimentent les rails. Fusion des idées d'ElectricTrainFix et de James-Train-Mod.

- **Version actuelle** : 0.3.26
- **Compatibilité** : Factorio 2.1, Space Age et Elevated Rails facultatifs
- [Récapitulatif puissances, consommation et recettes](ElectrifiedRailways/RECAP-ElectrifiedRailways.md)
- [Documentation complète](ElectrifiedRailways/README.md)

### [No Crafting Time](NoCraftingTime/README.md)
Un mod qui supprime les temps de fabrication dans Factorio. Toutes les actions sont effectuées instantanément en utilisant une petite quantité d'énergie électrique.

- **Version actuelle** : 2.1.0
- **Compatibilité** : Factorio 2.1
- **Dépendances** : Base >= 2.0.0
- [Documentation complète](NoCraftingTime/README.md)

## Installation
1. Clonez ce dépôt ou téléchargez-le en archive ZIP.
2. Copiez dans le dossier `mods` de Factorio uniquement le dossier du mod voulu (`ElectrifiedRailways` ou `NoCraftingTime`).
3. Pour Electrified Railways, n'installez pas en plus ElectricTrainFix ni James-Train-Mod : le mod les remplace.

Le script `build-mod.ps1` produit les archives installables dans `dist/`.
